# Play Grid Duel

The repository now contains a standalone Android Grid Duel game at `android-smoke/grid-duel-game`.

CI produces an installable debug APK named `grid-duel-android-game-apk`.

Game modes: AI practice, local two-player, Bluetooth Classic two-phone match, and authenticated Nearby two-phone match.

See `docs/grid-duel-android-game.md` for rules and evidence boundaries.
