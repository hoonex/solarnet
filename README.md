# SolarNet

SolarNet is a local-first multiplayer engine for turn-based games.

The first target is a 2D mobile game where nearby devices can play together without a traditional game server. The engine separates physical transport, room/lobby lifecycle, authoritative turns, and deterministic game-state recovery.

## Host-loss recovery foundation

A synchronized surviving peer can capture a trusted authority checkpoint. After the transport topology has selected a successor, `SolarAuthorityPromotion.CreatePromotedHost(...)` restores the canonical game state and `TurnCoordinator` into a **new game session ID**. Rotating the session ID is mandatory so delayed packets from the dead authority cannot contaminate the replacement authority epoch.

This is the deterministic state-transfer foundation for host migration, not yet automatic host election. See `docs/authority-checkpoint.md`.
